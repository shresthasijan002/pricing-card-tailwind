# SaaS Pricing Card Component (HTML & Tailwind CSS)

A clean, responsive SaaS pricing card UI component built with **HTML5** and **Tailwind CSS**. Designed to showcase subscription plan details with clear typography hierarchy, balanced spacing, and modern utility-first styling.

## Features
- **Centered Card Layout:** Elevated white card container with soft drop shadow and rounded corners.
- **Clear Typography Hierarchy:** Highlighted plan title, concise target audience subtitle, and prominent pricing display (`Rs. 999 /month`).
- **Feature Checklist:** Cleanly aligned feature list highlighting key plan benefits (`Unlimited Projects`, `100 GB free storage`, `Priority Support`).
- **Call-to-Action Button:** Styled primary action button (`Get Started`) ready for interactive hover and focus states.
- **Responsive Design:** Adapts cleanly across mobile, tablet, and desktop viewports.

## Tech Stack
- **HTML5**
- **Tailwind CSS**
